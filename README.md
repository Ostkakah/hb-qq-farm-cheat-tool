# QQ 农场机器人 · 单机版

**一个会自己浇水、除草、收菜、种地、养牧场的 QQ 农场小帮手。**

Windows 下双击一个 exe 就能跑，数据全部留在自己电脑上。

## 🌾 能做什么

| 类别 | 能力 |
| --- | --- |
| **农场** | 收菜 → 铲除 → 补种一条龙；一键浇水/除草/除虫；智能施肥；多季作物补肥；土地升级；防旱补草 |
| **种植策略** | 背包种子**按品质**优先（黄 > 紫 > 蓝 > 普通）；背包用完自动去商店补种；可选「最大净利润/时」「最大经验/时」等策略 |
| **牧场** | 自动入栏（按**当前牧场等级养得起的最高级**幼崽）、开始生产、收集产物、清理灾害、收获动物、投喂 |
| **好友** | 偷货架产物、帮清理灾害、照料动物、放蚊子、加牧草；白名单/黑名单、静默时段 |
| **日常** | 每日任务、邮箱、分享礼包、成长手册奖励 |
| **活动** | 限时活动做成插件，管理面板上传 zip 即装即用，不用重启 |
| **管理** | 多账号并行、Web 面板、实时日志、离线提醒、账号额度管理 |

## 🚀 快速开始

### 方式一：Windows 单机 exe（推荐给非技术同事）

1. 拿到 `qq-farm-bot-单机版.zip`，解压到任意目录
2. 双击 **`启动农场机器人.bat`**，浏览器会自动打开管理面板
3. 首次运行需要解压内置素材，约 1~2 分钟

| 文件 | 说明 |
| --- | --- |
| `qq-farm-bot.exe` | 主程序（自带 Node 运行时，无需装任何环境） |
| `启动农场机器人.bat` | 启动 + 自动打开面板 |
| `停止农场机器人.bat` | 停止 |
| `使用说明.md` | 给使用者的详细说明 |

**默认面板地址**：<http://localhost:3007>
**默认账号密码**：`admin` / `admin` —— **登录后第一件事就是改密码**

数据写在 exe 同级的 `data/` 目录，备份直接复制这个文件夹。

> 想换端口：设环境变量 `ADMIN_PORT`（如 `ADMIN_PORT=3010`）。

### 方式二：源码运行

需要 Node.js 20+ 和 pnpm 10+。

```bash
git clone https://github.com/Ostkakah/hb-qq-farm-cheat-tool.git
cd hb-qq-farm-cheat-tool

corepack enable
pnpm install
pnpm build:web
pnpm dev:core
```

打开 <http://localhost:3007> 即可。

### 方式三：Docker 部署

```bash
git clone https://github.com/Ostkakah/hb-qq-farm-cheat-tool.git
cd hb-qq-farm-cheat-tool
docker compose up -d --build
docker compose logs -f
```

| 用途 | 端口 / 目录 |
| --- | --- |
| Web 管理面板 | `3007` |
| 抓包代理（手机抓包登录用） | `18000` |
| 持久化数据 | 仓库上级目录的 `data/` |

## 🔑 登录方式

### 面板登录

管理面板需要登录，默认 `admin` / `admin`，**首次登录后请立刻修改密码**
（设置 → 账号管理）。

### 添加农场账号

点右上角 **「添加账号」**，选一种登录方式：

| 标签 | 适用 | 说明 |
| --- | --- | --- |
| **微信扫码** | 微信玩家 | 页面自动出二维码 → 手机微信扫 → 应用宝授权页确认。账号自动添加、自动开启 Code 刷新、自动开始收菜 |
| **QQ 扫码** | QQ 玩家 | 同样自动出二维码，手机 QQ 扫。**单机版开箱即用，不需要 NapCat** |
| 手动填码 | 备用 | 粘贴 Code 或 WebSocket 链接 |
| 抓包登录 | 手机抓包 | 需要安装并信任 CA 证书；抓包服务默认开启，端口 `18000` |

> **账号数量**：普通面板账号默认可加 **6 个**农场账号，管理员不限量。
> 在「后台 → 用户管理」里可以改额度，填 `-1` 表示不限。

## ⚙️ 自动化开关

统一在 **设置 → 账号设置**，按账号单独配置。

| 卡片 | 管什么 | 默认 |
| --- | --- | --- |
| **种植与收获** | 选种策略、巡田节奏、卖果实、优先 2×2、2×2 同步买种 | 全部开启 |
| **土地与施肥** | 施肥策略、土地升级、化肥补货 | 施肥开 / 升级关 |
| **好友** | 偷菜、帮助好友、捣乱、好友申请 | 偷菜帮助开 / 捣乱关 |
| **偷菜** | 巡查频率、操作延迟、白名单/黑名单 | 开 |
| **神秘商人** | 自动购买、货币范围 | 关 |
| **日常与活动** | 每日任务 + 各限时活动开关 | 任务开 |

### 选种策略

| 选项 | 行为 |
| --- | --- |
| **背包种子优先** | 先种背包里已有的种子，**按品质从高到低**：黄 > 紫 > 蓝 > 普通；品质相同再按所需等级降序 |
| 任务作物优先 | 优先种成长任务要求的作物 |
| 最大经验/时 | 按每小时经验排名选种 |
| 最大净利润/时 | 按每小时净利润（扣掉种子成本）排名选种 |
| 最高等级作物 | 选所需等级最高的作物 |
| 优先种植种子 | 手动指定某一颗种子 |

**「第二策略」**决定背包里的 1×1 种子用完后去商店买什么。建议用 **最大净利润/时**：
选「最贵作物」会一头撞进晚季高价种子（Lv114 账号会买 43200 金币/颗的依米花），
而「最大净利润/时」买 14400 金币/颗的莴笋，便宜 3 倍。

> 商店种子的「品质」几乎没有区分度——153 个种子里 151 个都是普通档，
> 所以在商店里该看的是**性价比**，不是品质。

### 牧场幼崽

自动入栏会养**当前牧场等级养得起的最高级**那档，而不是最低级的：

| 栏舍 | 品种阶梯（括号内是所需牧场等级） |
| --- | --- |
| 窝 | 鸡(1) → 鸭(3) → 鹅(9) → 兔子(11) → 火鸡(14) → 天竺鼠(17) → 乌龟(25) → 松鼠(27) → 刺猬(33) → 鼹鼠(35) → 考拉(41) → 狐狸(43) → 豪猪(49) → 龙猫(51) → 孔雀(58) → 貂(61) |
| 棚 | 羊(21) → 牛(23) → 驴(29) → 迷你猪(31) → 马(37) → 水牛(39) → 骆驼(45) → 牦牛(47) → 鸵鸟(53) → 梅花鹿(55) → 浣熊(64) → 羊驼(67) |

## ⚠️ 手机和机器人不能同时登录同一个号

**服务端对同一个农场只保留最新的一次登录。** 你用手机打开农场小程序，机器人会立刻被踢下线：

```
检测到踢下线，准备自动停止账号。原因: 已在其他终端登录
```

反过来也一样——机器人在你玩的时候重登，会把你手机顶下线。

所以：

- **想自己玩** → 先在面板里把**那个账号**点「停止」（= 暂停 30 分钟，期间机器人完全不登录它），再开小程序
- **机器人被踢了** → **5 分钟**后自动刷新凭证顶回去
- **账号掉线但没被踢**（断网、Code 失效等）→ 兜底巡检每分钟扫一次，离线超 90 秒就安排恢复

> 状态灯：🟢 在线 ｜ 🟡 暂停中 ｜ 🔴 离线
>
> 排查账号为什么没自动回来：看 **后台 → 账号日志**（不是主日志），那里有「降级重试」「刷新凭证失败」等真实原因。
> 连续失败会降级成 30 分钟重试一次，**不会彻底放弃**。

## ✨ 本仓库增强

相对上游 [Asunxu/qq-farm-bot](https://github.com/Asunxu/qq-farm-bot) 的改动：

### 账号与登录

- **新增「QQ 扫码」登录标签** —— 走 QQ 官方扫码换 Code，**单机版不再依赖 NapCat / Docker**
- 面板账号默认额度 2 → **6**，并修复了 `-1`（不限量）在后端不生效的问题
- 修复 localStorage 缓存旧额度导致「添加账号」按钮一直灰着的问题（启动时主动刷新用户信息）
- 手动「停止」改为 **暂停 30 分钟**语义：暂停期间不刷 Code、不保活、不重登，到点自动恢复；点「启动」立刻恢复

### 掉线自愈

- 踢线后 **5 分钟**自动重登（可用 `FARM_KICKOUT_RELOGIN_DELAY_MIN` 调整）
- 换 Code 请求加 **90 秒超时** —— 之前网络卡死会让账号一直离线到进程重启
- 新增 **离线兜底巡检**：任何原因掉线都能自动拉起
- 修复 **恢复配额被正常掉线烧光** 导致账号永久离线的缺陷（成功恢复不再消耗配额）
- 熔断改为 **降级重试**（30 分钟一次）而不是永久放弃；日志如实反映排班结果

### 牧场与种植

- 修复 `place` 被动作去重挡住 —— **同一栏位同一品种只放一次**，栏位永远填不满
- 自动入栏改为按 **牧场等级**挑最高级幼崽（原来永远塞最低级的鸭）
- 背包选种增加 **品质排序**（黄 > 紫 > 蓝 > 普通）
- 新增 **「最贵作物」策略**，商店补种不再只按经验/时选

### 打包

- 修复 pkg 打包后 **内置插件无法自举**（`fs.cpSync` 在 pkg 虚拟文件系统里不兼容，改为手工递归拷贝）
- 单机版启动脚本自动检测端口占用、依赖缺失与素材未构建

## ❓ 常见问题

**Q：面板打不开？**
A：确认启动脚本的窗口还开着；也可以直接浏览器访问 <http://localhost:3007>。

**Q：扫码二维码不出来？**
A：点「获取/刷新二维码」重新生成。首次生成要等几秒（要走应用宝的授权服务器）。

**Q：账号显示离线，一直连不上？**
A：多半是微信侧登录凭证过期了。去账号设置点「刷新 Code」；还不行就重新扫码。
详细原因看「后台 → 账号日志」。

**Q：机器人把我的号顶下线了 / 我把机器人顶下线了？**
A：同一个号只能有一端在线。见上面「手机和机器人不能同时登录同一个号」。

**Q：会被封号吗？**
A：有可能。自动化操作可能违反游戏服务条款，封号风险自己承担。
建议别开太激进的设置（比如「土地升级」会大量花金币）。

**Q：数据在哪？怎么备份？**
A：全部在 exe 同级的 `data/` 目录。复制整个 `data/` 就是完整备份。

**Q：怎么改巡田节奏？**
A：设置 → 账号设置 → 种植与收获 → 巡田间隔（默认 2~5 秒随机）。

## 🛠️ 开发与构建

```bash
pnpm install          # 安装依赖
pnpm build:web        # 构建前端
pnpm dev:core         # 启动后端
pnpm dev:web          # 启动前端开发服务器
pnpm lint             # 代码检查
pnpm -C core test     # 后端测试
```

打单机版 exe（需要 Node 20+）：

```bash
pnpm -C core build:win     # core/dist/qq-farm-bot.exe
```

> `core/dist/` 与 `web/dist/` 都在 `.gitignore` 里，不入库。

### 目录结构

```text
hb-qq-farm-cheat-tool/
├── core/                 # 后端、自动化引擎与协议实现
│   ├── src/              # 服务、模型、协议、运行时
│   ├── plugins/          # 内置活动插件
│   ├── test/             # 后端测试
│   └── dist/             # 打包产物（不入库）
├── web/                  # Vue 3 管理面板
│   └── src/              # 页面、组件、store
├── docs/                 # 使用文档
└── docker-compose.yml
```
