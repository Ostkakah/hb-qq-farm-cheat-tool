# QQ 农场机器人 · 单机版使用说明

> 一个会自己浇水、除草、收菜、种地的 QQ 农场小帮手。
> 全部数据都存在你自己电脑上，不上传任何服务器。

---

## 一、这是什么

把 QQ 农场（微信小程序版）的日常操作自动化：

| 能干的事 | 说明 |
| --- | --- |
| 收菜 + 补种 | 作物成熟自动收，收完自动买种补上 |
| 浇水 / 除草 / 除虫 | 巡田时发现脏了顺手清理 |
| 智能施肥 | 按需施肥，多季作物自动补肥 |
| 偷好友菜 | 好友的菜成熟了去偷一把 |
| 好友帮助 | 帮好友浇水除草除虫 |
| 日常任务 | 自动领每日任务、邮箱、礼包奖励 |
| 土地升级 | 可选，花金币升土地等级 |
| 限时活动 | 奶茶、节令等活动插件自带开关 |

---

## 二、运行要求

- **Windows 64 位**（Win10 / Win11）
- **无需安装 Node.js、无需 Python、无需 Docker**
- 首次运行会自动解压内置插件素材，约需 1~2 分钟
- 想长期跑建议接一台旧电脑/小主机，别放在会关机的笔记本上

---

## 三、启动

双击 **`启动农场机器人.bat`**。

- 机器人会在后台跑起来，浏览器自动打开管理面板
- 面板地址：<http://localhost:3007>
- **关掉那个黑色命令行窗口不会停止机器人**，要停请双击 `停止农场机器人.bat`

如果提示端口被占用，说明已经有一个在跑了，直接开浏览器看面板就行。

## 四、首次使用（三步）

### 第 1 步：登录面板

浏览器打开 <http://localhost:3007>，用默认账号登录：

```
用户名：admin
密码：admin
```

> ⚠️ **登录后立刻去「设置 → 账号管理」把密码改掉。**

### 第 2 步：添加农场账号

点右上角 **「添加账号」**，选一种登录方式：

| 标签 | 怎么用 | 说明 |
| --- | --- | --- |
| **微信扫码** | 页面自动弹二维码 → 手机微信扫 → 应用宝授权页确认 | 推荐，链路最稳 |
| **QQ 扫码** | 页面自动弹二维码 → 手机 QQ 扫 | 单机版直接可用，不需要额外装东西 |
| 手动填码 | 粘贴 Code 或 WebSocket 链接 | 备用 |
| 抓包登录 | 手机连代理抓包 | 需要装 CA 证书，较麻烦 |

**微信扫码步骤**：
1. 页面自动弹出二维码（没弹就点「获取/刷新二维码」）
2. **用手机微信扫码**，在应用宝授权页点确认
3. 授权成功后账号自动添加、自动开启 Code 自动刷新、自动开始收菜

**QQ 扫码步骤**：
1. 切到「QQ 扫码」标签，页面自动弹二维码（点二维码可刷新）
2. **用手机 QQ 扫描**，必要时在 QQ 里点确认
3. 成功后自动带出昵称和头像并入库

> 「QQ·NapCat」标签只在 Docker 版启用了 NapCat 时才出现，它额外能做 QQ 好友同步，单机版用不到。

**加更多号**：重复同样的流程即可。普通面板账号默认最多 **6 个**农场账号（管理员不限量）；不够的话在「后台 → 用户管理 → 编辑用户」里改额度，填 `-1` 表示不限。

### 第 3 步：确认自动化开关

进 **「设置 → 账号设置」→「种植与收获」**，确认这个卡片是**开启**状态（默认就是开的）。

| 卡片 | 管什么 | 默认 |
| --- | --- | --- |
| 种植与收获 | 巡田、收菜、选种、出售、巡田节奏 | 开 |
| 土地与施肥 | 施肥策略、土地升级、化肥补货 | 施肥开 / 升级关 |
| 好友 | 帮好友浇水除草、好友申请 | 开 |
| 偷菜 | 巡查好友农场偷菜 | 开 |
| 神秘商人 | 自动购买 | 关 |
| 日常与活动 | 每日任务 + 各限时活动开关 | 任务开 |

## 五、日常使用

### 面板速览

| 位置 | 看什么 |
| --- | --- |
| **农场** | 每块地的作物状态，可以手动点「收获」「种植」 |
| **牧场** | 窝/棚的栏位占用、产出、可入栏幼崽 |
| **好友** | 好友列表、偷菜记录、帮助记录 |
| **活动** | 限时活动面板（奶茶、节令等） |
| **设置 → 账号设置** | 每个账号单独的自动化开关 |
| **后台 → 实时日志** | 机器人每一步在干什么，排查问题先看这里 |
| **后台 → 活动插件** | 活动插件的安装/升级/卸载 |

### 常用操作

- **手动收一次菜**：农场页 → 「收获」按钮
- **临时让某个号休息**：账号设置 → 该账号 → 「停止」
- **马上恢复**：同一个按钮点「启动」

### 种植策略

在 **设置 → 账号设置 → 种植与收获** 里选：

| 选项 | 行为 |
| --- | --- |
| **背包种子优先** | 先种背包里已有的种子，**按品质从高到低**：黄 > 紫 > 蓝 > 普通；品质相同再按所需等级降序 |
| 任务作物优先 | 优先种成长任务要求的作物 |
| 最大经验/时 | 按每小时经验排名选种 |
| 最大净利润/时 | 按每小时净利润（扣掉种子成本）排名选种 |
| 最高等级作物 | 选所需等级最高的作物 |
| 优先种植种子 | 手动指定某一颗种子 |

> **第二策略**（背包里 1x1 种子用完、必须去商店买时用哪个）默认是 **最高等级作物**：
> 买当前账号等级**解锁的最高级**那档种子（Lv129 → 金边灵芝 17568 金币，
> Lv131 → 薄荷 26352 金币）。想省钱可以换成「最大净利润/时」。
>
> ⚠️ 种子商店里**品质几乎没有区分度**——153 个种子里 151 个都是普通档，
> 只有仙人掌（9240 金币，需 199 级）是紫色。所以商店里该看的是**等级/性价比**，不是品质。
>
> 想省钱还可以把「背包优先清单」排好序——机器人会严格按你排的顺序种背包里的种子。

### 牧场自动化

牧场（窝 / 棚）和农场是两套独立开关，在 **设置 → 账号设置 → 牧场设置** 里按模块开：

| 模块 | 管什么 |
| --- | --- |
| 养殖 | 自动入栏、开始生产、收集产物、清理灾害、收获动物 |
| 投喂 | 补充牧草、装填罐头容器、使用罐头喂食 |
| 好友 | 帮助好友清理灾害、照料好友动物、给好友加牧草 |
| 偷取 | 偷取好友货架产物 |
| 商人 | 出售产物、用便便 / 松果兑换 |

**栏位填不满、看着有空位却没买新动物**，通常是这两个原因：

1. **幼崽品种选错**。`鸡` 是 4 秒就长熟的占位动物，放进去立刻被收走，占位永远不涨。栏位要填满应该用成长周期长的品种（鸭 1 小时、羊 3 小时、牛 6 小时）。
2. **牧场等级 / 设施没解锁**。窝和棚本身要先解锁、升级，服务器没开放的栏位机器人不会强行开——这种会显示「设施尚未解锁」，需要你手动在游戏里推进。

**放入的幼崽是"当前牧场等级养得起的最高级"那档**，不是最低级的：

| 栏舍 | 品种阶梯（括号内是所需牧场等级） |
| --- | --- |
| 窝 | 鸡(1) → 鸭(3) → 鹅(9) → 兔子(11) → 火鸡(14) → 天竺鼠(17) → 乌龟(25) → 松鼠(27) → 刺猬(33) → 鼹鼠(35) → 考拉(41) → 狐狸(43) → 豪猪(49) → 龙猫(51) → 孔雀(58) → 貂(61) |
| 棚 | 羊(21) → 牛(23) → 驴(29) → 迷你猪(31) → 马(37) → 水牛(39) → 骆驼(45) → 牦牛(47) → 鸵鸟(53) → 梅花鹿(55) → 浣熊(64) → 羊驼(67) |

> 也就是说：牧场等级越高，机器人自动买越高级的幼崽。
> 想限定只养某几种，在「牧场设置 → 养殖」里改品种清单即可；
> 清单为空则这一轮不放任何幼崽。
>
> 牧场买动物花的是**金券**（松鼠 12672、迷你猪 12672、火鸡 5640…），等级越高越贵。

## ⚠️ 六、特别重要：手机和机器人不能同时登录同一个号

**服务器对同一个农场只保留最新的一次登录。** 实测确认，你用手机微信打开 QQ 农场小程序，机器人会立刻被踢下线，日志里写的是：

```
检测到踢下线，准备自动停止账号。原因: 已在其他终端登录
```

反过来也一样——机器人在你玩的时候重登，会把你手机顶下线。

所以：

- **想自己玩** → 先在面板里把**那个账号**点「停止」，等机器人不再动它，再开小程序玩
- **机器人被踢了** → **5 分钟**后会自动刷新凭证顶回去，不用管
- **「停止」的含义是暂停 30 分钟**，期间机器人完全不登录这个号（不刷 Code、不保活、不重登），30 分钟后自动恢复自动化。想立刻恢复就点「启动」
- **账号掉线了但没被踢**（比如网络断了、Code 失效）→ 兜底巡检每分钟扫一次，离线超过 90 秒就安排恢复

> ⚠️ 5 分钟重登意味着：**你正在手机端玩的时候，机器人 5 分钟后会把你顶下线**（服务端只认最新登录）。
> 想安静玩超过 5 分钟，一定要先点「停止」把那个号暂停掉。
>
> 重登间隔可以用环境变量 `FARM_KICKOUT_RELOGIN_DELAY_MIN` 调整（单位：分钟，默认 5）。
> 兜底巡检间隔用 `FARM_OFFLINE_SWEEP_INTERVAL_MS`（毫秒，默认 60000）调整。

> 排查账号为什么没自动回来：看面板 **后台 → 账号日志**，里面记着「自动重登已熔断 / 降级重试 / 刷新凭证失败」等真实原因。
> 连续失败会降级成 **30 分钟**重试一次（不会彻底放弃）；网络或凭据恢复后会自动回到 5 分钟节奏。

> 状态灯说明：绿点=在线，黄点=暂停中，红点=离线。

## 七、常见问题

**Q：面板打不开？**
A：确认黑色窗口还开着。也可以在浏览器里手动访问 <http://localhost:3007>。

**Q：明明密码是对的，却提示"密码错误"？**
A：多半是 3007 端口上跑了**两个实例**（比如源码版和 exe 版各一个），你打开的页面属于另一个，它有自己独立的账号库。
检查一下任务管理器里有没有多个 `node.exe` / `qq-farm-bot.exe`；或者给其中一个设 `ADMIN_PORT=3010` 换端口跑。

**Q：扫码二维码不出来？**
A：点「获取/刷新二维码」重新生成。首次生成要等几秒（要走应用宝的授权服务器）。

**Q：账号显示离线，一直连不上？**
A：多半是微信那边的登录凭证过期了，去账号设置点「刷新 Code」；还不行就重新扫码。

**Q：会被封号吗？**
A：有可能。自动化操作可能违反游戏服务条款，封号风险自己承担。建议别开太激进的设置（比如「土地升级」会大量花金币）。

**Q：数据在哪？怎么备份？**
A：全部在 exe 同级的 `data/` 目录。直接复制整个 `data` 文件夹就是完整备份。

**Q：想换端口？**
A：设置系统环境变量 `ADMIN_PORT`，比如 `ADMIN_PORT=3010`，然后重启。
